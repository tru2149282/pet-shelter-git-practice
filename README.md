# Pet Shelter Practice Project

## Project Overview

The Pet Shelter Practice Project is a simple Python program that models pets and a pet shelter. It demonstrates how Python classes and objects can work together to store pet information, search for pets, and perform basic actions.

## Files

* `pet.py` defines the `Pet` class and contains information and behaviors for individual pets.
* `shelter.py` defines the `Shelter` class and manages a collection of Pet objects.
* `main.py` creates sample pets and a shelter and demonstrates how the classes work together.

## Classes

### Pet

The `Pet` class represents an individual pet. Each pet has a name, species, and age. It also includes methods for describing the pet and celebrating a birthday.

### Shelter

The `Shelter` class represents a pet shelter. It stores Pet objects and provides methods for adding pets, listing pets, and finding a pet by name.

## Run the Project

Run the program from the project directory with:

```bash
python3 main.py
```

## Features

* Create pets with a name, species, and age.
* Add pets to a shelter.
* Display all pets currently in the shelter.
* Find a pet by name.
* Celebrate a pet's birthday.
* Detect senior pets that are 8 years old or older.
* Count the number of pets currently in the shelter.
* Adopt a pet by name and remove it from the shelter.
